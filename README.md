# 제품 제안 대시보드

태성정밀 개발기획팀 — 부품 · 상품 제안용 대시보드

- **판매가 산출**: 매입원가 → BEP → 대리점가(최종 유통가, 제안 최저가) → 소비자가(대리점가 × 2), 영업이익률별 단가표, 유통가 보고 PPT
- **부품 대체**: 기존 매입단가 · 사용량(판매 + BOM 소요량) 대비 신규 단가 · 금형비 회수 수량 · 기간, 이익률 개선, PPT
- **신규 제안서**: 라인업 · 세트 · 입고가 · 판매가 검토를 입력하면 제안서 PPT 자동 생성
- **팀즈 보내기**: 파워오토메이트 흐름(설정 탭 안내) 또는 팀즈 채팅 링크

데이터는 쉐어포인트 MMS 폴더의 `구매현황_전체_최신.xlsx`, `판매현황_전체_최신.xlsx`, `BOM_최신.xlsx`를 화면에 끌어다 놓아 연결합니다.
입력한 내용과 MMS 데이터는 각자 브라우저에만 저장되며, 이 저장소에는 올라가지 않습니다.
