# 제품 제안 대시보드

태성정밀 개발기획팀 — 부품 · 상품 제안용 대시보드

- **판매가 산출**: 매입원가 → BEP → 대리점가(최종 유통가, 제안 최저가) → 소비자가(대리점가 × 2), 영업이익률별 단가표, 유통가 보고 PPT
- **부품 대체**: 기존 매입단가 · 사용량(판매 + BOM 소요량) 대비 신규 단가 · 금형비 회수 수량 · 기간, 이익률 개선, PPT
- **신규 제안서**: 라인업 · 세트 · 입고가 · 판매가 검토를 입력하면 제안서 PPT 자동 생성
- **팀즈 보내기**: 파워오토메이트 흐름(설정 탭 안내) 또는 팀즈 채팅 링크

## 데이터 — 쉐어포인트(MMS)에서 가져오기

- 사내 로컬PC(MMS)가 평일 07~19시 매시간 이카운트 자료를 쉐어포인트 `TDC › 문서 › MMS` 에 올립니다.
- **데이터 · 설정** 탭에서 회사를 고르고 **쉐어포인트에서 가져오기**를 누르면, 회사 마이크로소프트 계정으로 로그인해
  `MMS/<회사>/구매현황_전체`, `판매현황_전체`, `BOM` 의 `_최신.xlsx` 를 읽습니다.
- 한 번 로그인하면 열 때(그리고 30분 넘게 지나 다시 볼 때) 파일 eTag 를 보고 바뀐 파일만 창 없이 다시 받습니다.
- 공통 코드: `mms-sharepoint.js` (발주현황 · 구매요청 · 판매현황 대시보드와 같은 파일), 로그인 후 돌아오는 주소는 발주현황의 `auth.html`.
- 앱 등록에 Microsoft Graph **Sites.Read.All**(위임) 권한이 있어야 합니다.
- 쉐어포인트를 못 쓰는 경우 같은 파일을 화면에 끌어다 놓아도 됩니다.
입력한 내용과 MMS 데이터는 각자 브라우저에만 저장되며, 이 저장소에는 올라가지 않습니다.
