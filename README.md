# 제품 제안 대시보드

태성정밀 개발기획팀 — 부품 · 상품 제안용 대시보드

- **판매가 산출**: 매입원가 → BEP → 대리점가(최종 유통가, 제안 최저가) → 소비자가(대리점가 × 2), 영업이익률별 단가표, 유통가 보고 PPT
- **부품 대체**: 검토 하나에 여러 품목을 + 로 추가. 품목별 기존 매입단가 · 사용량(판매 + BOM 소요량) 대비 신규 단가 · 금형비, 검토 합계로 총 투자 · 연간 절감 · 회수 기간 · 이익률 개선, PPT
- **신규 제안서**: 라인업 · 세트 · 입고가 · 판매가 검토를 입력하면 제안서 PPT 자동 생성
- **팀즈 보내기**: 파워오토메이트 흐름(설정 탭 안내) 또는 팀즈 채팅 링크

## 데이터 — 쉐어포인트(MMS)에서 가져오기 (발주현황 대시보드와 같은 방식)

- 사내 로컬PC(MMS)가 평일 07~19시 매시간 이카운트 자료를 쉐어포인트 `TDC › 문서 › MMS` 에 올립니다.
- 대시보드를 열면 이 브라우저에 쉐어포인트 로그인 기록이 있을 때 창 없이 **태성정밀 · 플로우텍** 두 회사의
  `구매현황_전체`, `판매현황_전체`, `BOM` 최신 파일 eTag 를 확인하고 바뀐 파일만 받아 합칩니다 (30분 넘게 지나 다시 볼 때도 확인).
- 처음 한 번은 위쪽 줄의 **📥 쉐어포인트 자료 가져오기** 를 누르면 회사 계정 로그인 창이 뜹니다.
- 그룹사 거래(태성정밀 ↔ 플로우텍)는 항상 판매량에서 빼고, 최근 매입단가는 외부 공급사 매입을 우선합니다.
  같은 생산품목 BOM 이 두 회사에 다 있으면 태성정밀 것만 씁니다.
- 공통 코드: `mms-sharepoint.js` (발주현황 · 구매요청 · 판매현황 대시보드와 같은 파일), 로그인 후 돌아오는 주소는 발주현황의 `auth.html`.
- 쉐어포인트를 못 쓰는 경우 같은 파일을 화면에 끌어다 놓아도 됩니다.
입력한 내용과 MMS 데이터는 각자 브라우저에만 저장되며, 이 저장소에는 올라가지 않습니다.
