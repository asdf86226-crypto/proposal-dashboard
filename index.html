판매가 산출 — 대리점가 · 소비자가

파란 글씨 칸만 입력합니다. 품목코드를 넣으면 이카운트 품명과 최근 매입단가를 불러옵니다(데이터 · 설정 탭에서 MMS 파일을 연결한 경우). 판관비율 · 영업이익률 칸을 비우면 기본값이 적용되고, 대리점가 칸에 값을 넣으면 계산값 대신 그 값을 씁니다. 금액은 모두 부가세 별도입니다.

영업이익률별 대리점가 —

대리점가는 제안하는 최저가입니다. 영업팀은 이 표에서 이익률을 올리거나(더 비싸게) 내려서(더 싸게) 단가를 정하면 됩니다. 표 위 행을 누르면 그 품목으로 바뀝니다.

이카운트 데이터 (쉐어포인트 MMS)

쉐어포인트에서 바로 가져오기

회사 마이크로소프트 계정으로 로그인하면 MMS 폴더의 구매현황 · 판매현황 · BOM 최신 파일을 직접 읽습니다. 한 번 로그인해 두면 대시보드를 열 때마다(그리고 30분 넘게 지나 다시 볼 때) 바뀐 파일만 자동으로 다시 받습니다. 발주현황 · 구매요청 대시보드와 같은 로그인입니다.

또는 파일을 직접 넣기

쉐어포인트 TADC 사이트 → 문서 → MMS → 태성정밀(또는 플로우텍) 폴더의 아래 세 파일을 한 번에 골라 넣으세요. 내 PC 탐색기의 'OneDrive - 태성정밀(주)' 바로가기에서 고르면 됩니다. 파일 종류는 머리글을 보고 알아서 구분합니다.

  • 구매현황_전체\구매현황_전체_최신.xlsx — 최근 매입단가 · 구매수량
  • 판매현황_전체\판매현황_전체_최신.xlsx — 품목별 판매량 · 판매단가
  • BOM\BOM_최신.xlsx — 부품이 들어가는 제품의 판매량을 부품 사용량으로 환산
여기에 파일을 끌어다 놓거나

태성정밀 → 플로우텍처럼 회사끼리 넘긴 수량을 판매량에서 뺄지 정합니다. 플로우텍이 다시 외부에 파는 제품이면 빼지 않는 편이 실제 사용량에 가깝습니다.

월평균 환율표

한 줄에 연월, USD, CNY 형식으로 적습니다. 예: 2026-11, 1340.20, 200.50

원가 · 이익 기준

판매가 산출표(설정 시트)와 같은 값입니다.

매출 대비: 대리점가 = 매입원가 ÷ (1 − 판관비율 − 영업이익률). 원가 가산: 매입원가 × (1+판관비율) × (1+영업이익률).

팀즈 보내기 설정

링크(claude.ai)로 연 대시보드에서는 보안 정책상 자동 발송이 막혀 있어 'PPT 저장 → 팀즈 채팅 열기' 방식으로 동작합니다. 자동 발송은 HTML 파일로 열었을 때만 됩니다.

파워오토메이트 흐름 주소를 넣으면 'PPT를 원드라이브에 저장 → 받는 사람에게 팀즈 채팅으로 링크 발송'까지 버튼 한 번으로 끝납니다. 비워 두면 PPT를 내려받고 팀즈 채팅 창을 열어 주므로, 파일을 끌어다 놓아 보내면 됩니다.

파워오토메이트 흐름 만드는 법
  1. make.powerautomate.com → 만들기 → 인스턴트 클라우드 흐름 → 트리거 "HTTP 요청을 받은 경우". (프리미엄 커넥터입니다. 라이선스가 없으면 아래 '대안'을 쓰세요.)
  2. 요청 본문 JSON 스키마에 아래 내용을 붙여 넣습니다. 
    {"type":"object","properties":{
 "fileName":{"type":"string"},"fileContent":{"type":"string"},
 "message":{"type":"string"},"recipients":{"type":"string"},
 "title":{"type":"string"}}}
  3. OneDrive for Business → 파일 만들기: 폴더 /제품제안, 파일 이름 fileName, 파일 콘텐츠 식 base64ToBinary(triggerBody()?['fileContent'])
  4. OneDrive for Business → 공유 링크 만들기: 방금 만든 파일 ID, 링크 형식 '보기', 범위 '조직'
  5. 각각에 적용: 식 split(triggerBody()?['recipients'], ',') → 안에 Microsoft Teams → 채팅 또는 채널에 메시지 게시 (게시자 '흐름 봇', 게시 위치 '흐름 봇과 채팅', 받는 사람 trim(item()), 메시지에 message와 공유 링크)
  6. 응답 동작을 추가해 상태 코드 200을 돌려줍니다. 저장하면 트리거에 생기는 HTTP 주소를 위 칸에 붙여 넣으세요.

대안 (프리미엄 없이): 트리거를 "OneDrive for Business — 파일이 생성될 때"(폴더 /제품제안)로 바꾸고 3~5단계를 그대로 둡니다. 받는 사람은 영업팀 채널로 고정합니다. 대시보드에서 내려받은 PPT를 OneDrive의 제품제안 폴더에 저장하면 자동으로 팀즈에 올라갑니다.
